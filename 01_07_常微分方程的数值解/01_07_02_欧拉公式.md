# 2 欧拉公式的局部截断误差和阶数

y(x_n+1) 是 真实值
y_n+1 是计算得到的计算值 
O(h^2) 指的是 比h^2 更高阶的项

![](image/Pasted%20image%2020260317003257.png)


阶数怎么判断 见下面
![](image/Pasted%20image%2020260316235811.png)

如果局部阶段误差 符合 O(h^(p+1 )) , 就是说  误差项  中含有的item  的次数 大于 h^(p+1 )  , 为 大于等于 p+1 次的 
则 该方法为  p阶的

基本思想是用 用泰勒展开 去 算 方法的阶数

![](image/Pasted%20image%2020260317004309.png)

y_n+1 是计算得到的计算值 
O(h^2) 指的是 比h^2 更高阶的项


![](image/Pasted%20image%2020260317004636.png)

y(x_n+1)  - y_n+1  =  y(x_n+1)  - y_n - hxf(x_n+1, y_n+1)

得到 
y(x_n+1)  - y_n+1  =  y(x_n+1)  - y(n)  - h 乘上 f(x_n+1, y_n+1)



![](image/Pasted%20image%2020260317164404.png)

注意最后一个公式应该是 - h^2 /2    ,  没有错 

得到 隐式的欧拉公式是 1阶的, 因为 余项是中 h最高次卫 是h的2次方


## 2.3 梯形公式的的 局部截断误差 和相应的阶

显式欧拉公式 的局部截断误差 和 隐式欧拉公式 的局部截断误差  加起来 除以2 , 则 h^2 正好抵消掉 ， 这样误差的阶数就能提高了 


可以看到 梯形公式就是 显式欧拉公式 和 隐式欧拉公式 的加权平均

![](image/Pasted%20image%2020260317194603.png)

显式公式 是 y_n+1 = y_n + hf(x_n, y_n)
隐式公式 是 y_n+1 = y_n + hf(x_n+1, y_n+1)
则他们两相加除以2 就是梯形公式 y_n+1 = y_n + h/2 `[f(x_n, y_n), f(x_n+1, y_n+1)]`

又 他们俩的局部截断误差为 
![](image/Pasted%20image%2020260317195647.png)

则梯形公式的 局部截断误差为  他们俩的截断误差相加除以2 , 得到 
![](image/Pasted%20image%2020260317200839.png)

得到 隐式公式 中的 梯形公式是 2阶的, 因为 余项是中 h最高次卫 是h的三次方
