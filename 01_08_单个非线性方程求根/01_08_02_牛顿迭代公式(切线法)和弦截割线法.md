## 2.1 牛顿迭代 如何算阶数

((x_k+1) - x*) / ( (x_k - x*)^p )  
当 k 趋向于无穷的时候,   
- ((x_k+1) - x*) / ( (x_k - x*)^p )   的值为 常数, 不为0,  
- (x_k+1) - x*) / ( (x_k - x*)^(p-1) )   的值为 为0,  
则称这个迭代函数为 p 阶的 

![](image/Pasted%20image%2020260403175710.png)

上面截图中的 下面的公式
用相邻的三个点 来算, 如果 不能等于0, 就是2阶的


## 2.2 如果 根为 重根, 则迭代函数的阶数就是1阶的. 根为单根, 迭代阶数就位2阶

迭代公式的一阶导数等于0, 迭代公式的2阶导数不等于0, , 迭代公式就是2阶收敛   (p-1=1, p=2 )
